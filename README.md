## 🚀 How to Run the Website (For Users)

This repository is **100% self-contained** and runs out-of-the-box on any device without requiring package managers or build steps.

### Method 1: Instant Browser Launch (No Installation Required)
Simply double-click `index.html` in the root folder. The platform will open immediately in your default web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari).

### Method 2: 1-Click Launch Scripts
* **On Windows:** Double-click `start.bat`.
* **On macOS / Linux:** Open a terminal in the folder and run:
  ```bash
  chmod +x start.sh
  ./start.sh
  ```

### Method 3: Local Node.js Server
If you have Node.js installed, run:
```bash
node server.js
```
The server will start at `http://localhost:8080/` and automatically open your default browser.

### Method 4: Local Python Server
```bash
# Python 3
python -m http.server 8080
```
Then navigate to `http://localhost:8080/index.html`.

## 🌐 How to Deploy to GitHub Pages (Free Web Hosting)

To share this website live on the web via GitHub Pages:

1. Push this repository to your GitHub account (e.g. `https://github.com/<your-username>/water-technology-intelligence-hub`).
2. On your GitHub repository page, click **Settings** (gear icon) → **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   * **Source:** Select `Deploy from a branch`.
   * **Branch:** Choose `main` (or `master`), select folder `/ (root)`, and click **Save**.
4. In ~60 seconds, your site will be live at:
   `https://<your-username>.github.io/water-technology-intelligence-hub/`

*(Alternatively, the pre-configured GitHub Actions workflow in `.github/workflows/deploy.yml` will automatically build and publish your site upon push!)*
